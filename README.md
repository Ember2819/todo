# Tabtask

A todo list extension that saves your tabs.

Add a task and attach tabs to it — they close and reopen when you click the task. Press `Alt+Shift+S` to turn the current tab into a task instantly. You can also set reminders that pop up as notifications.

The theme matches your browser, and you can tweak colors, fonts, and the dither pattern in settings. Works as a popup or a pinned side panel.

## Install

**Chrome/Brave/Edge:** `chrome://extensions` → enable Developer mode → Load unpacked → pick this folder.

**Firefox 121+:** `about:debugging#/runtime/this-firefox` → Load Temporary Add-on → pick `manifest.json`.
